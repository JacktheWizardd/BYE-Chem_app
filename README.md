# BYE Chem

A chemistry learning app and website for everyone, from complete beginners up to Chem 1A/1B and AP. It has the same structure and look as BYE Math: numbered chapters, Learn pages, and Simple / Medium / Hard practice, plus a Lab of sandboxes and everyday Tools.

**Status:** design settled, demo app in progress. See [AGENTS.md](AGENTS.md) for the current status and the rules every change follows.

- [docs/chapter-map.md](docs/chapter-map.md): the chapters and sections in our own beginner order, each mapped to the class textbook.
- [docs/practice-layer.md](docs/practice-layer.md): how learners practise (answer first, checked answers, fading, spaced review).
- [design/](design/): HTML mockups. [reports/](reports/) and [docs/research/](docs/research/): the research behind the design.

The 3D chemistry figures come from [BYE Chem Engine](https://github.com/JacktheWizardd/BYE-Chem_engine), and graphs from [BYE Math Engine](https://github.com/JacktheWizardd/BYE-Math_engine). All teaching content is our own.
